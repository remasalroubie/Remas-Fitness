# Remas Fit

A personal fitness web app I built in Arabic, designed as a Progressive Web App (PWA).

🔗 [remasalroubie.github.io/Remas-Fitness](https://remasalroubie.github.io/Remas-Fitness)

---

## About

I wanted a simple Arabic-language app to help track workouts and stay consistent. So I built one. It works on mobile and can be installed like a regular app through the browser.

---

## Features

- Arabic interface
- Workout tracking
- Works offline (PWA)
- Installable on mobile

---

HTML · CSS · JavaScript
